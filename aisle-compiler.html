Grocery aisle editor

Pair your aisle compiler

The current grocery widget opens directly in Studio. For a custom Dart version that has never been built, your Windows computer can compile the Flutter preview and send it to the same editor.

Download Windows launcher
  1. Double-click the downloaded Windows x64 launcher. It verifies its private Python runtime and compiler kit. If Flutter 3.38.3 is missing, it asks before downloading the SDK into your user folder.
  2. Keep the compiler window open. In the grocery aisle editor, choose Pair compiler and approve the connection on your computer.
  3. Upload your Dart in the editor. When the build finishes, the phone opens that version. You can select products and edit their sizes.

If the browser asks for local access

Allow Sleipnir Studio to connect to your computer. The compiler uses the loopback address and keeps the private build on your device. Closing its window stops the service.
